# 말모이 언어학교

듀오링고처럼 하루 5분씩 여러 나라 말을 배우는 웹 앱이에요.

- `index.html` 하나만 열면 바로 돼요. (설치 필요 없음)
- 목록에 있는 474개 언어를 모두 보여 주고, 그중 145개 언어는 지금 바로 배울 수 있어요.
- 나머지 언어는 "준비 중"이에요. 틀린 단어를 가르치지 않으려고, 단어를 확인한 언어부터 열어요.

## 배우는 것

5개 단원, 기초 단어 10개: 안녕하세요, 고마워요, 네, 아니요, 물, 하나, 둘, 셋, 엄마, 잘 가요

## 기능

- 문제 3종류: 뜻 고르기, 외국어 고르기, 짝 맞추기
- 하트 5개, 경험치, 연속 학습일
- 틀린 문제는 끝에 한 번 더 나와요
- 소리 듣기 (브라우저에 그 언어 목소리가 있을 때)
- 진행 상황은 브라우저에 저장돼요

## 언어 추가하기

`index.html` 안의 `const L = { ... }` 에 한 줄을 넣으면 돼요.

```js
"언어 이름": ["음성코드", "안녕하세요", "고마워요", "네", "아니요", "물", "하나", "둘", "셋", "엄마", "잘 가요"],
```

라틴 문자가 아니면 `"글자|읽는 법"` 처럼 적어요. 예: `"Привет|privet"`
